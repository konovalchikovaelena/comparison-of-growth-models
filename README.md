# Comparison of Growth Models

## Overview

This repository contains code for comparing growth models in a research context.

The main analysis is provided in the Jupyter Notebook:

`Comparison_of_growth_models_2026_new.ipynb`

## Repository Contents

- `Comparison_of_growth_models_2026_new.ipynb` — Jupyter Notebook containing the analysis and model comparison.

## Requirements

- Python 3
- Jupyter Notebook or JupyterLab
- Python packages required by the notebook

## How to Run

1. Clone or download this repository.
2. Install the required Python packages.
3. Open the notebook in Jupyter Notebook, JupyterLab, or Google Colab.
4. Run the notebook cells in order.

Please ensure that the required input data and software dependencies are available before running the analysis.
